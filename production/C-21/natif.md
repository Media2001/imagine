1. WordPress fournit Outils → Exporter les données et Effacer les données, avec demandes natives identifiées par email ou identifiant ; documentation : https://wordpress.org/documentation/article/tools-export-personal-data-screen/.
2. L’exporteur natif produit une archive ZIP HTML/JSON ; les extensions déclarent leurs callbacks paginés dans `wp_privacy_personal_data_exporters` : https://developer.wordpress.org/plugins/privacy/adding-the-personal-data-exporter-to-your-plugin/.
3. L’effaceur natif anonymise/retire les données déclarées, mais ne supprime pas le compte WordPress ; la suppression du compte reste une action administrative distincte : https://developer.wordpress.org/plugins/privacy/adding-the-personal-data-eraser-to-your-plugin/.
4. Sur WordPress 7.0.9 installé, décocher « Envoyer un email de confirmation » crée directement une demande confirmée ; « Télécharger les données personnelles » n’envoie pas le lien par email ; les deux parcours POST/AJAX ont été exercés.
5. WooCommerce déclare coordonnées du client, commandes et téléchargements ; l’inventaire officiel est dans https://woocommerce.com/document/configuring-woocommerce-settings/accounts-and-privacy/#personal-data-exporter.
6. L’effacement et les durées sont pilotés par Comptes et confidentialité ; durée vide signifie absence de purge programmée, non une durée juridique choisie : https://woocommerce.com/document/configuring-woocommerce-settings/accounts-and-privacy/#personal-data-retention.
7. Subscriptions 9.4.1 installé déclare abonnements et données Gifting (`WCS_Privacy_Exporters`, `WCSG_Privacy_Exporters`) ; callbacks officiels réellement enregistrés et exécutés : `conservation-complete.json`, `http-complet.json`.
8. Son retrait des données est opt-in ; le code officiel `WCS_Privacy_Erasers` annule avant anonymisation lorsqu’il est activé ; ici l’option effective vaut `no`, donc l’abonnement actif reste actif, comme le décrit aussi la section Subscriptions des réglages officiels WooCommerce cités ligne 6.
9. Memberships déclare export/effacement des adhésions ; « Account Erasure Requests » commande leur suppression, ici désactivée : https://woocommerce.com/document/woocommerce-memberships-settings/ ; callbacks officiels `WC_Memberships::export_personal_data` et `::erase_personal_data` relus sur le site.
10. C21 étend ces outils, pas leurs règles comptables : aucun réglage conservatoire modifié, aucune commande/adhésion/souscription effacée en plus du standard ; les jetons de paiement sont exclus de l’export Imagine, leur effaceur natif reste enregistré.
