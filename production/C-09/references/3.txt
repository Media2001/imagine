Code Reference WP-CLI Commands Home Reference Functions wp_insert_user() Search wp_insert_user( array|object|WP_User $userdata ): int| WP_Error In this article Table of Contents Description Parameters Return Source Hooks Related Changelog User Contributed Notes Copy page View as Markdown Back to top Inserts a user into the database. Description Most of the $userdata array fields have filters associated with the values. Exceptions are &#8216;ID&#8217;, &#8216;rich_editing&#8217;, &#8216;syntax_highlighting&#8217;, &#8216;comment_shortcuts&#8217;, &#8216;admin_color&#8217;, &#8216;use_ssl&#8217;, &#8216;user_registered&#8217;, &#8216;user_activation_key&#8217;, &#8216;spam&#8217;, and &#8216;role&#8217;. The filters have the prefix &#8216;pre_user_&#8217; followed by the field name. An example using &#8216;description&#8217; would have the filter called &#8216;pre_user_description&#8217; that can be hooked into. Parameters $userdata array|object| WP_User required An array, object, or WP_User object of user data arguments. ID int User ID. If supplied, the user will be updated. user_pass string The plain-text user password for new users. Hashed password for existing users. user_login string The user&#8217;s login username. user_nicename string The URL-friendly user name. user_url string The user URL. user_email string The user email address. display_name string The user&#8217;s display name. Default is the user&#8217;s username. nickname string The user&#8217;s nickname. Default is the user&#8217;s username. first_name string The user&#8217;s first name. For new users, will be used to build the first part of the user&#8217;s display name if $display_name is not specified. last_name string The user&#8217;s last name. For new users, will be used to build the second part of the user&#8217;s display name if $display_name is not specified. description string The user&#8217;s biographical description. rich_editing string Whether to enable the rich-editor for the user. Accepts 'true' or 'false' as a string literal, not boolean. Default 'true' . syntax_highlighting string Whether to enable the rich code editor for the user. Accepts 'true' or 'false' as a string literal, not boolean. Default 'true' . comment_shortcuts string Whether to enable comment moderation keyboard shortcuts for the user. Accepts 'true' or 'false' as a string literal, not boolean. Default 'false' . admin_color string Admin color scheme for the user. Default 'modern' . use_ssl bool Whether the user should always access the admin over https. Default false. user_registered string Date the user registered in UTC. Format is &#8216;Y-m-d H:i:s&#8217;. user_activation_key string Password reset key. Default empty. spam bool Multisite only. Whether the user is marked as spam. Default false. show_admin_bar_front string Whether to display the Admin Bar for the user on the site&#8217;s front end. Accepts 'true' or 'false' as a string literal, not boolean.
