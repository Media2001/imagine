# Fusion B-13 — menu principal et menu étendu

Lot : B-13. Brief : `briefs/B-13-menu-principal-et-menu-etendu.md`. Cahier des charges : §3.1.
Rapports fusionnés : `relectures/B-13/claude.md` (verdict « Conforme ») et `relectures/B-13/codex.md` (verdict « À corriger »).

Le fusionneur a rouvert le code et les preuves pour trancher les divergences. Verdicts opposés : Codex a vu deux choses importantes que Claude a manquées. Sur un troisième point, le fusionneur abaisse la gravité retenue par Codex.

## 1. Points retenus par les deux relecteurs

- **Structure conforme au §3.1.** Menu natif conservé, enrichi par le filtre natif `walker_nav_menu_start_el` ; listes `<ul>/<li>` imbriquées, lisibles sans JavaScript ; aucun style ni animation ajoutés. Huit entrées dans l'ordre, une seule fois, « S'abonner » → page d'attente déclarée, « Connexion » documenté (libellé conservé, destination Mon compte). Les deux rapports concordent.
- **Étanchéité (« Rien de réservé »).** Le fragment n'émet que titre, image à la une et lien ; jamais extrait ni corps. Requête `post_status = publish` et `post_password => ''`. Les témoins C-26 et le marqueur `EXTRAIT_B13_INTERDIT_DANS_MENU_` sont absents du menu, avec contre-épreuve positive du détecteur. Aucune voie de fuite. Les deux rapports concordent.
- **Doctrine §5.** Typage strict, espace de noms `Imagine\Site`, préfixe `imagine_`, textes traduits, aucune extension tierce modifiée (un seul filtre). Cinq lignes « standard » sourcées dans le README. Les deux rapports concordent.
- **Sécurité du réglage.** `manage_options`, Settings API + nonce de `options.php`, valeur bornée 1–10 via `nombre()`, échappement systématique des sorties. Les deux rapports concordent.
- **Thématique vide conservée.** `hide_empty => false`, pas de sous-liste si aucun article. Vérifié par `thematique_vide_conservee`. Les deux rapports concordent.
- **Couverture PHPUnit scellée étroite.** Le seul test scellé (`NavigationB13Test`) ne couvre que `nombre()` ; l'essentiel de la preuve repose sur les scripts runtime/navigateur, non rejoués hors-ligne. Claude le classe mineur, Codex le constate aussi. Retenu mineur.

Note d'exécution : Claude a rejoué la suite scellée (REJEU PASS). Codex n'a pas pu démarrer le PHPUnit ciblé (WSL `E_ACCESSDENIED`) et s'est limité à `verifier.py` + `qualifier.py` (PASS). Aucun des deux n'a rejoué les essais natifs/navigateur en direct (hors droits du relecteur) : les deux s'appuient sur les JSON archivés pour le comportement de `thematiques()`. Le léger écart de compte du rejeu (1208 tests / Claude ; 1205 / Codex) reflète deux états de run ; non significatif.

## 2. Points vus par un seul relecteur, avec l'avis du fusionneur

### Vus par Codex seul

- **B13-01 — Important — Sélection d'articles non illustrée dans la démonstration.** `Navigation.php:123`. **Retenu, important.** Vérifié par le fusionneur : dans `browser-final-V2.json`, surface `anonyme`/`/`, la thématique 20 montre trois articles (`4081`, `44`, `37`) mais un seul `<img>` — celui de l'article fictif B-13. Les articles de démonstration pré-existants (44, 37, 43, 36, 45, 42…) n'ont pas d'image à la une : six des neuf articles sélectionnés sortent sans illustration. Le §3.1 et le brief exigent « une sélection d'articles illustrés / titre, image à la une, lien ». Le code est correct (il émet la miniature *si* elle existe), mais la preuve de la démonstration contredit « articles illustrés ». **Claude a manqué ce point** : son Cas A a conclu « conforme ; confirmé par `browser-final-V2.json` » sans compter les images. Codex avait raison contre Claude.

- **B13-02 — Important — Le rejeu ne rétablit pas le lien « S'abonner ».** `b13-seed.php:14`. **Retenu, important.** Mécanisme confirmé par le fusionneur en relisant `b08-seed.php` : l'entrée `abonnement` est réécrite **à chaque passage** de B-08 vers `home_url('/#imagine-abonnement')` (`b08-seed.php:73`, appliquée sans condition par `$put`, `:130-134`). B-13 corrige le raccord à `b13-seed.php:31`, mais si l'option `imagine_b13_fixture` existe déjà, `b13-seed.php:14-16` retourne **avant** la ligne 31. Séquence B-08 → B-13 → B-08 → B-13 : au second passage, B-08 remet l'ancienne ancre et B-13 ne la répare plus. « S'abonner » peut donc ne plus pointer vers la page d'attente alors qu'un état de livraison est annoncé. Constat par analyse (non rejoué sur instance, comme Codex le précise). Aucun test ne vérifie l'URL de l'entrée `abonnement` après re-seed. Contrevient à la reproductibilité (doctrine §4). **Claude a manqué ce point** : il a validé « S'abonner → page d'attente » sans tester l'idempotence du re-seed.

- **B13-03 — Codex : important ; fusionneur : mineur — Invalidation absente sur retrait direct de relation de thématique.** `Navigation.php:16`. **Retenu, mais abaissé à mineur** (désaccord de gravité, voir §3). Le cache écoute `set_object_terms` mais pas `deleted_term_relationships` : un `wp_remove_object_terms()` ne déclenche pas l'invalidation. Gap réel. **Mais** une recherche sur tout le dépôt ne trouve aucun usage de `wp_remove_object_terms()` : tous les retraits passent par `wp_set_object_terms()` (chemin couvert), y compris le test `b13-runtime.php:47`. Le chemin non couvert n'est donc exercé nulle part aujourd'hui, et le fragment se reconstruit de toute façon à l'expiration (un jour). Gravité mineure. Correctif cheap, à appliquer par prudence.

- **B13-04 — Mineur — Assertion insuffisante sur le nombre d'articles par thématique.** `b13-runtime.php:53`. **Retenu, mineur.** Vérifié : `substr_count($small, 'data-b13-article=') <= count($terms)` est satisfait par zéro article comme par une mauvaise répartition. Le test ne prouve pas que le réglage s'applique à chaque thématique.

### Vus par Claude seul

- **Sur-invalidation sur `save_post`.** `Navigation.php:16`. **Retenu, mineur.** `save_post` invalide pour toute écriture (révisions, enregistrements automatiques), pas seulement les publications. Sans danger (reconstruction), simple sur-invalidation. À filtrer sur le type de post ou laisser tel quel ; sans urgence.
- **Dépendance à la classe `imagine-nav-thematiques`.** `Navigation.php:83-84`. **Retenu, mineur.** Si un administrateur retire cette classe de l'entrée B-08, le menu étendu disparaît en silence. Fragilité héritée de B-08, non introduite ici ; à noter.
- **Ordre alphabétique des thématiques (`orderby name`).** Non fixé par le cahier des charges. Décision technique, voir §5.

## 3. Désaccords

- **Verdict global.** Claude conclut « Conforme », Codex « À corriger ». Le fusionneur tranche pour **« À corriger »** : B13-01 et B13-02 sont réels et touchent la preuve de la démonstration (§3.1) et la reproductibilité (§4). Codex avait raison contre Claude.
- **Gravité de B13-03.** Codex : important. Fusionneur : **mineur**. Motif : le chemin `wp_remove_object_terms()` / `deleted_term_relationships` n'est exercé nulle part dans le dépôt (tout passe par `set_object_terms`, couvert) et le cache expire en un jour. Le correctif reste demandé (cheap, défensif), mais ne bloque pas. Si un lot futur introduit un `wp_remove_object_terms()`, la gravité remonte.

## 4. Instructions pour Hermès (numérotées)

1. **(B13-01, important)** Donner une image à la une à chaque article de démonstration retenu dans la sélection, de sorte que les neuf articles affichés dans le menu étendu soient illustrés. Ne pas masquer le problème en remplaçant silencieusement un article récent sans image par un plus ancien. Vérifier chaque article sélectionné individuellement, sur les six surfaces archivées.
2. **(B13-01, important)** Décider et documenter le comportement quand un article récent n'a pas d'image à la une (le laisser sans image, un placeholder neutre, ou l'exclure). Le §3.1 dit « articles illustrés » mais ne traite pas ce cas : c'est une interprétation à écrire. Appliquer le défaut technique proposé en §5, puis documenter le choix dans le README.
3. **(B13-02, important)** Rendre le raccord « S'abonner » → page d'attente idempotent au rejeu : même quand `imagine_b13_fixture` existe, revérifier et réappliquer `_menu_item_url` sur l'entrée `abonnement` détenue, en conservant son identifiant, avant le retour anticipé de `b13-seed.php:14`.
4. **(B13-02, important)** Ajouter un test de séquence B-08 → B-13 → B-08 → B-13 qui vérifie la destination finale de « S'abonner » (page d'attente) et l'absence de doublon d'entrée.
5. **(B13-03, mineur)** Ajouter `deleted_term_relationships` à la liste des hooks d'invalidation (`Navigation.php:16`), et couvrir par un test le retrait direct d'une relation après construction du cache (renouvellement de la sélection, terme devenu vide conservé).
6. **(B13-04, mineur)** Renforcer `b13-runtime.php:53` : sur des thématiques fictives assez fournies, comparer les identifiants attendus par thématique pour les réglages 1, 3 et 10 (ordre date DESC puis ID DESC), tout en gardant un cas distinct pour la thématique vide.
7. **(Claude, mineur)** Au choix : filtrer l'invalidation sur `save_post` par type de post pour éviter la sur-invalidation sur révisions/autosaves, ou laisser tel quel et le noter. Sans urgence.
8. **(Claude, mineur)** Noter dans le README la dépendance du menu étendu à la classe `imagine-nav-thematiques` de l'entrée B-08 (disparition silencieuse si la classe est retirée).

## 5. Décisions techniques, défaut proposé (Hermès applique, arbitrage a posteriori)

- **Article récent sans image à la une (B13-01/instruction 2).** Défaut prudent : laisser l'article sans image plutôt qu'inventer un habillage ou l'exclure. Hermès applique ; Claude arbitre après coup.
- **Ordre des thématiques dans le menu étendu.** Le code applique l'ordre alphabétique (`orderby name`), non fixé par le §3.1. Défaut proposé : garder l'alphabétique. Hermès applique sans attendre.

## 6. À arbitrer par Ced (visuel / touchant au réel, questions fermées)

- **Libellé « Connexion » pour un lecteur déjà connecté.** L'entrée garde le mot « Connexion » (comportement B-01/natif retenu), destination « Mon compte ». Faut-il garder « Connexion » même connecté, ou afficher « Mon compte » ? Défaut prudent : garder « Connexion » tant que la maquette ne tranche pas.
- **Forme du menu étendu.** Panneau latéral ou grand déroulant : non livré, arbitré sur maquette (§3.1). Défaut : livrer contenu et structure seuls, forme validée sur maquette. Rien à corriger côté code.

## Verdict fusionné

**À corriger.**

- **Bloquant** : aucun.
- **Important** : B13-01 (six articles sélectionnés sans image, preuve non illustrée) ; B13-02 (lien « S'abonner » non rétabli au rejeu).
- **Mineur** : B13-03 (invalidation absente sur retrait direct de relation, chemin non exercé aujourd'hui) ; B13-04 (assertion faible sur le nombre par thématique) ; sur-invalidation `save_post` ; dépendance à la classe `imagine-nav-thematiques` ; couverture PHPUnit scellée étroite.

Rappel : **un verdict n'est pas un GO.** Il reste la validation visuelle de Ced (libellé « Connexion », forme du menu) et l'application des corrections ci-dessus avant toute mise en production.
