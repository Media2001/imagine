# A-03 — mode d’emploi
1. Exécuter seulement sur copie fictive ou staging déjà vérifié, jamais en production ; A-03 prolonge l’audit A-02 et ne donne aucun GO réel.
2. Conserver le MU de sécurité de `wp/outils/staging/` et `.imagine-staging-verified.json` intacts ; blocages courrier, réseau, passerelles et ordonnanceurs recontrôlés nativement.
3. Copier `wp/tests/a03-non-regression/exemple.json` hors du site ; adapter mois UTC, IDs restreints, sept chemins relatifs et marqueurs publics ; même configuration avant/après, comptes administratifs exclus des représentants.
4. Photo : `php wp/outils/bascule/non-regression --wp-path=/site-verifie --config=/travail/config.json --output=/travail/avant` ; compte SQL SELECT seulement ; erreur SQL = refus technique, aucun rapport valide produit.
5. Rejouer vers `apres`, puis `php wp/outils/bascule/comparer /travail/avant/non-regression.json /travail/apres/non-regression.json` ; codes : 0 identique, 2 anormal, 3 attendu/à regarder, 1 refus de collecte, écriture ou comparaison.
6. Photo complète exigée en référence, pages disparues ensuite = anormal ; sonde et photo non interchangeables ; clés contrôlées, chemins libres masqués, aucune valeur avant/après exportée ; toutes les actions restent suivies sans liste d’exceptions.
7. Seule écriture opt-in : `--renewal-test` avec SQL inscriptible ; rapport distinct `mode=renewal_probe`, commande native manuelle impayée puis nettoyage et annulation transactionnelle ; aucun paiement, AUTO_INCREMENT pouvant avancer.
8. Rejeu fictif : `python wp/tests/a03-non-regression/run.py --name nom-nouveau` ; pur/T01 : `python wp/tests/a03-non-regression/phpunit.py --name autre-nom` ; WSL/Docker, image et ZIP acceptés par A-02 déjà présents ; sorties uniquement dans le scratch Hermes, aucun PHP Windows.
9. Limites : site simple sans drop-in DB/cache, sonde InnoDB ; douze mois UTC, montants séparés par devise, GET visiteur sans session ni redirection hors site ; `php_error` ne voit que les erreurs affichées, fatal silencieux seulement si HTTP défaillant ; journaux et étanchéité servie hors A-03, arbitrages `corrections/A-03.md` §5 toujours ouverts.
