8. Écriture opt-in : `--renewal-test` avec SQL inscriptible ; sonde distincte `mode=renewal_probe`, commande native manuelle impayée, nettoyage/rollback ; aucun paiement, AUTO_INCREMENT pouvant avancer ; étanchéité paywall servie hors A03 (C-08/C-11).
